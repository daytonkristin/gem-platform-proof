## Pre-purchase compatibility check
Run `python3 verify_gem_compat.py` for Python, OpenSSL Ed25519, and SQLite checks. For an optional real inference probe, configure `GEM_MODEL_BASE_URL`, `GEM_MODEL_FAST`, `GEM_MODEL_SAFE`, and optionally `GEM_MODEL_API_KEY`, then run `python3 verify_gem_compat.py --live`. The live probe sends synthetic prompts to both models and may incur charges. PASS confirms only the tested prerequisites, not full product compatibility or production readiness.

## Contents
- `verify_gem_compat.py`: standard-library-only pre-purchase environment probe.
- `architecture.svg`: high-level deployment and request-flow diagram.
- `endpoint-schema.json`: OpenAPI schema generated by the actual FastAPI app, which disables the public `/openapi.json` endpoint.
- `routing-audit-sample.json`: synthetic requests routed through the real router with mocked localhost model responses; not a live inference quality benchmark.
- `TECHNICAL_FAQ.md`: exact implementation requirements, local inference setup, SQLite and SIG1 behavior.
