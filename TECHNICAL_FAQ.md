# gem-platform — Codebase-verified technical FAQ

**Verified against commit `786eb65` and the standalone implementation.** Documentation files `BUYER_SETUP.md` and `STANDALONE.md` contain historical engineering-candidate and unreleased language that does not match the subsequently enabled release flags; the implementation and current release configuration take precedence for technical behavior.

**What runtime is required?** Python 3.11 or later, OpenSSL supporting Ed25519, and the Python packages `fastapi`, `uvicorn`, `httpx` (plus transitive dependencies). The provided setup instructions use `pip install fastapi uvicorn httpx`. The current test environment uses Python 3.13. No Docker, Kafka, Grafana, or Prometheus is required for the standalone router. A writable directory is required for SQLite and the process needs access to the bundled public key.

**How do I start it?** From `services/router_service`, set `GEM_API_KEY` to a private string of at least 16 characters, set `GEM_SIG1_LICENSE` to the purchased SIG1 token, optionally set `GEM_SQLITE_PATH` to a private writable file, then run `uvicorn standalone:app --host 127.0.0.1 --port 8080`. Without a valid license and API key, the application will not instantiate successfully. `GET /health` is public; `GET /policy` and `POST /route` require `Authorization: Bearer <GEM_API_KEY>`. API documentation, dashboard and metrics endpoints are disabled in the standalone app.

**How is local Ollama or vLLM configured?** Set `GEM_MODEL_BASE_URL` to an OpenAI-compatible `/v1` endpoint (example `http://127.0.0.1:11434/v1` for a locally configured compatible server), `GEM_MODEL_FAST` and `GEM_MODEL_SAFE` to valid model IDs served by that endpoint, and `GEM_MODEL_API_KEY` if required. The adapter POSTs to `<GEM_MODEL_BASE_URL>/chat/completions` with a non-streaming chat-completions request. Both model IDs are mandatory when inference is configured. Loopback HTTP is permitted; non-loopback model endpoints must use HTTPS. The repository does not bundle Ollama, vLLM, models, or a server installer, and compatibility depends on the configured server's API behavior.

**Can it operate air-gapped?** The router's licensing verification uses a pinned public Ed25519 key and OpenSSL locally, and SQLite stores metadata locally. If Python dependencies, the commercial license, and a compatible inference server/model are already available on the isolated host, no remote model service is required. A configured remote inference URL would transmit prompt content to that endpoint. The source does not prove that all third-party dependencies or model downloads can be installed in a fully isolated environment without preparation.

**How does routing work?** The standalone app computes a confidence score and uses the policy's confidence/drift thresholds. FAST routes to `GEM_MODEL_FAST`; SAFE and SHADOW both call `GEM_MODEL_SAFE` (the adapter receives SAFE for non-FAST decisions). FALLBACK does not call a model. If no adapter is configured, output is `null` with status `fallback:inference_not_configured`. HTTP/model-response errors return `fallback:model_unavailable`. The demonstration forces FAST and SAFE with different drift values and uses mock responses; it does not demonstrate real model accuracy.

**What is persisted in SQLite?** The `events` table is created as `id INTEGER PRIMARY KEY, request_id TEXT NOT NULL, route TEXT NOT NULL, status TEXT NOT NULL`. Each `/route` request inserts its request ID, routing decision and status. The table has no prompt or response-content column. The default path is `gem-platform.sqlite3` unless `GEM_SQLITE_PATH` is set. This is local routing-event metadata persistence, not an encrypted database or a complete compliance audit ledger.

**How is the license verified?** The license must be a `SIG1` token with a canonical base64url payload and a 64-byte Ed25519 signature. `sig1.verify()` checks its signature with `config/trusted_issuer.pem`, exact required fields, edition `commercial`, seats (1–100000), timezone-aware issuance/expiry, and `product: gem-platform`. Validation occurs at application startup and for every authenticated protected request. The private issuer key is not included in the commercial ZIP. A SignalIndex-scoped token cannot activate gem-platform.

**What is the API request/response?** POST `/route` accepts `input` (string), optional `drift` (float, default 0), optional `request_id` (UUID generated if absent). Response keys: `request_id`, `route`, `confidence`, `latency_ms`, `model_version`, `output`, `status`. See the generated `endpoint-schema.json` for the exact FastAPI request schema. GET `/policy` reports standalone mode and whether inference is configured.

**What security constraints remain?** Standalone authentication is a shared bearer API key, not per-user identity. Do not expose the service publicly without TLS, request limits, network restrictions and secret management. Model endpoints receive the submitted prompt. The included proof pack contains no proprietary implementation or live signing credentials.
